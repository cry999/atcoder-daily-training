## 比較した案

## 再実行

公式ツールの `tools` ディレクトリで `cargo build --release --bins` を実行してから、次のように採点する。

```sh
c++ -O3 -std=c++17 ahc/ahc074_a.cpp -o /tmp/ahc074
python3 ahc/ahc074/benchmark.py /path/to/tools --executable /tmp/ahc074 --cases 100 --jobs 4 --json /tmp/ahc074-results.json
python3 ahc/ahc074/benchmark.py /path/to/tools --cases 100 --jobs 4 --previous
python3 ahc/ahc074/benchmark.py /path/to/tools --cases 100 --jobs 4 --baseline
```

`--previous` は初版の 4 窓方式、`--baseline` は 1 窓 2 枚方式。通常の提出用コードにはオプションを渡さない。初版の方策表再生成用コードは比較の再現のため残してある。

`--executable` を省くと Python 前版を実行する。C++ 版はローカル比較用に `./solver 14 6000000 4 400000 12 1000` のように取っ手数・最大反復数・最大クラスタサイズ・群割当反復数・順位係数・設計CPU上限msを指定できる。ベンチマークからは `--solver-arg` を引数ごとに繰り返して渡せる。提出時は引数を使わない。
